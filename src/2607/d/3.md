# D3 Архитектура набора инструкций RISC-V

> #### hint::Слайды и видео
>
> Содержимое конспекта пока ещё не готово. Материалы по программированию смотрите в разделе PA, упомянутом ниже. Пока что для изучения вы можете обратиться к [слайдам](https://ysyx.oscc.cc/slides/2306/08.html#/) и [видео](https://www.bilibili.com/video/BV15h4y1A7Up).

После повторения программирования на C через PA1 вы уже можете использовать C для реализации симулятора процессора RISC-V! Реализация этого симулятора позволит вам получить начальное представление о наборе инструкций RISC-V и поведении процессора, а также подготовит вас к следующему этапу — реализации настоящего процессора на RTL.
