# E2 Программирование на языке C

<!--
Although OSOC aims to teach you how to design a processor chip, you will still frequently deal with software because processor chips are different from other types of chips. Therefore, to understand how to make programs run better, you first need to understand how they run on a processor.
-->
Хотя OSOC (сокращение от «One Student One Chip») ставит целью научить вас проектировать процессорный чип, вам всё равно придётся часто иметь дело с программным обеспечением, поскольку процессорные чипы отличаются от прочих типов чипов. Поэтому, чтобы понять, как сделать так, чтобы программы работали лучше, вам сначала нужно понять, как они выполняются на процессоре.

<!--
C language is the best choice to help you to understand this problem, and considering that many of the students participating in "One Student One Chip" project do not have a computer science background, C is relatively easy to learn. You should be familiar with the following: recursion, pointers, linked lists, and be able to write a correct program on your own rather than relying on sample code you find on Google. 
-->
Язык C — лучший выбор, чтобы помочь вам разобраться в этом вопросе, а поскольку многие студенты, участвующие в проекте «One Student One Chip», не имеют образования в области информатики, C относительно легко изучить. Вы должны быть знакомы со следующим: рекурсия, указатели, связные списки — и уметь самостоятельно написать корректную программу, а не полагаться на примеры кода, найденные в Google.
